# Java Lab Report Template

Use this structure for Chinese Java course experiment reports. Keep claims tied to the actual code and test output.

## 实验目的

State the Java concept and practical goal, such as object-oriented design, collection management, exception handling, file persistence, JDBC CRUD, GUI event handling, or multithreaded programming.

## 实验环境

Include:

- 操作系统
- JDK 版本
- IDE 或命令行工具
- 数据库/依赖库 if relevant

## 实验内容与需求分析

Summarize what the program must do. Mention required classes, input/output, persistence, GUI/database requirements, and constraints.

## 总体设计

Describe modules/classes:

- Entity classes and fields
- Manager/service classes and main methods
- UI or menu layer
- File/database/thread/network layer if relevant

For UML requests, provide Mermaid class diagram text unless the user needs an image.

## 核心代码说明

Explain 2-4 important methods or code blocks. Do not paste excessive code. Mention why each part is important.

## 测试过程与结果

Provide test cases in a table:

| 测试编号 | 输入/操作 | 预期结果 | 实际结果 |
| --- | --- | --- | --- |
| 1 | 正常添加记录 | 添加成功并可查询 | 通过 |

Use real command output or screenshots when available.

## 问题与解决方法

List concrete issues encountered, such as encoding, package path, Scanner newline, SQL connection, or file path problems, and explain the fix.

## 实验总结

Summarize what was implemented and what Java knowledge was practiced. Keep it natural and student-like; avoid exaggerated claims.
