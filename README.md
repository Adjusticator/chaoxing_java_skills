# chaoxing_java_skills

用于学习通 Java 面向对象实验的 Codex skill，主要帮助完成大学 Java 课程中的实验作业、代码实现、编译运行、样例验证和简单实验报告整理。

## 适用场景

- 学习通上的 Java 面向对象程序设计实验
- 类与对象、继承、接口、多态、集合、异常、文件 IO、简单 GUI、JDBC、线程、Socket 等常见课程实验
- 老师给出 PDF、Word、图片、样例输入输出或半成品代码，需要整理成可运行 Java 程序
- 需要把多个 `.java` 文件合并成课堂/在线评测更容易提交的单文件版本
- 需要检查编译错误、运行错误、输出格式不匹配等问题

## 适用工具

目前主要面向 **Codex** 使用。

Claude Code 是否完全适用我没有充分验证。理论上其中的提示词、参考文档和脚本仍然有参考价值，但工具调用、skill 加载方式和执行习惯可能不同，使用前建议自己检查并调整。

## 效果预期

这个 skill 的目标是让 Java 实验作业更稳定地达到较完整、可运行、可解释的状态。正常题型下，配合明确的实验要求和样例测试，完成效果大概率能在九十分左右。

但这不是保分承诺，也不排除特殊情况，例如：

- 老师有隐藏格式要求或口头要求
- 学习通/在线评测有严格类名、包名、输出空格限制
- PDF 识别有误，题目内容被抽取错
- 实验要求包含截图、报告、UML、数据库环境或 IDE 工程配置
- 教师评分更重视个人编码风格、课堂过程或查重结果

提交前一定要自己看一遍代码和输出，确认符合老师要求。

## 使用建议

使用前请尽量提供：

- 实验要求文件，如 PDF、Word、截图
- 老师给出的样例输入输出
- 已有代码或项目文件夹
- 提交要求，如类名、文件名、是否必须 `Main.java`
- 是否需要实验报告、截图或运行说明

推荐提示方式：

```text
这是实验要求，请根据文件夹内的代码完成这个 Java 面向对象实验。
要求：
1. 生成可运行代码
2. 保持输出格式和样例一致
3. 编译并运行样例测试
4. 如果有异常输入，加入合理处理
```

如果需要单文件提交，可以明确说：

```text
请把这个实验合并成一个 Main.java，保证完整性、可信性和异常处理能力。
```

其中：

- `references/`：Java 实验常见流程、测试清单和报告模板
- `scripts/java_lab_check.py`：用于编译和运行普通 Java 项目的辅助脚本

## 注意事项

- 不要直接无脑提交生成结果，至少检查一次题目要求、类名、输出格式和样例结果
- 如果老师要求多文件、包名、Maven/Gradle、GUI 或数据库工程，不要强行合成单文件
- 如果代码用于在线评测，避免多余提示语，输出必须贴合样例
- 如果用于课程报告，不要伪造截图或测试结果
- 如遇到特殊评分规则，以老师要求优先
